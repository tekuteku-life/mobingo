# 外部設計書

## 1. 適用範囲

本書は[要求仕様書](requirements.md)の利用者・保存・外部入力に対する契約の定義である。画面配置は[UI設計書](ui_design.md)、アルゴリズムは[内部設計書](internal_design.md)の責務である。

## 2. 入出力契約

| ID | 対応要求 | 契約 |
| --- | --- | --- |
| E-01 | R-01、R-12 | 起動時の役割は`select`、`child`、`host`である。未知の保存値は`select`へ戻す。役割変更は各ゲームを保持する |
| E-02 | R-02〜04 | IDは`0123456789ABCDEFGHJKMNPQRSTVWXYZ`の4文字である。手入力は大文字化、空白・ハイフン除去、O/I/L補正、許容文字抽出、先頭4文字の順で補正する。4文字未満は開始しない |
| E-03 | R-04〜06 | カードはIDに固定される。中央FREE以外をタップ開封する。開封済みの短いタップでは閉じず、600ms長押しで閉じる。400〜599msでは開封しない |
| E-04 | R-05、R-16 | pointercancel、画面離脱、縦横いずれか10px以上の移動で操作を中止する。別pointerの開始・移動・終了は進行中の操作に作用しない。キャンセルから開封や抽選を実行しない |
| E-05 | R-06、R-11 | 待ち数字は未開封1マスのラインから算出する。複数役が同時成立し得る。参加者の特殊役ONは表示と手元判定の指定であり、開催者の解禁手番を変更しない |
| E-06 | R-07、R-08 | 抽選はスライド完了後に回転し、約1.8秒後に球を表示し、約5秒後に1手を保存する。各演出を樽タップでスキップできる。抽選中の二重開始は無効である |
| E-07 | R-08、R-11 | Undoは0手で無効、確認取消で無変更、承認で1手戻る。特殊役は一度だけ解禁し、Undoで解禁以前へ戻っても解禁予定手番を保持する。リセットは手番と解禁状態を初期化する |
| E-08 | R-09 | モードAは参加者IDの重複登録を拒否し、0人で開始させない。削除後に再登録できる。親IDは受付前入力を維持し、受付終了で一覧の編集を停止し、固定した一覧と出目の導出完了後に保存して生成結果を確定する。受付中にアプリが閉じた場合の一覧保存は現行では未対応である |
| E-09 | R-09、R-10 | QRの内容は`mobingo:child:<4文字ID>`または正規の4文字IDである。QRは手入力用の任意文字削除・切り詰めを使わず、ペイロード全体の形式を検査する。無関係なURLや長文を受付しない |
| E-10 | R-10、R-11 | 照合は現在手番までの出目でカードを再現する。最初の有効手番、同時成立役、全成立役、一致数0〜24を算出する。0手は未達成、75手は全12標準ラインが成立する |
| E-11 | R-12 | 保存は下表のキーを使う。JSON破損・型不一致・範囲外・不正IDは復元せずセットアップへ戻す。任意HTMLやプロパティを信頼しない。利用不能・容量超過時も未捕捉例外を出さない |
| E-12 | R-13 | 初回オンラインで全資産を取得後、キャッシュ優先で再訪する。更新時はMobingoの旧キャッシュだけを消去する。GET以外はSWで横取りしない |
| E-13 | R-14、R-15 | 表示可能領域の高さとsafe areaへ追従し、開始・セットアップ・受付は必要時に指で内部スクロールできる。投影・情報・QR・照合モーダルを閉じられる。開催者ヘッダー右端の投影ボタンと、投影ヘッダー右端の戻るボタンは44px以上の高さでほぼ同じ位置に置く。投影は上部操作を固定し、スマートフォンの75数字は横15数字・縦5行で全件を表示する。カメラ非対応・拒否時は手入力へ切替可能である。音声・振動・Wake Lock失敗はゲーム結果に影響しない |
| E-14 | R-16 | 遷移で旧画面を破棄する。破棄後に解決したPromiseは描画・保存しない。カメラは遅れて取得されても全trackを停止する。終了した画面のタイマー・監視は残さない |

## 3. 保存形式

| localStorageキー | 内容 |
| --- | --- |
| `mobingo_app_mode` | `select` / `child` / `host`の文字列 |
| `mobingo_child_state` | `{ childSeed, openedCellCoords, specialRuleActive }`のJSON |
| `mobingo_parent_state` | `{ parentSeed, mode, currentTurn, specialRuleTurn, registeredChildSeeds }`のJSON |

`childSeed`と`parentSeed`は正規4文字ID、座標は`"0,0"`〜`"4,4"`の配列、特殊役フラグはbooleanである。`mode`は`mode_a`または`mode_b`、`currentTurn`は0〜75の整数、`specialRuleTurn`はnullまたは0〜75の整数、参加者一覧は重複のない正規ID配列である。Undoにより`specialRuleTurn > currentTurn`となる状態は有効である。FREEは保存有無によらず開封扱いである。余分なプロパティは復元時に捨てる。

リセットは対応するゲームキーを削除する。役割選択キーと他方のゲームキーは削除しない。ブラウザの保存データ消去、プライベートモード終了、端末紛失からの復旧は提供しない。

## 4. セキュリティ境界・制限

QRと4文字IDはカード再現用であり署名・本人認証ではない。開催者の照合が示すのは当該カードと当該出目の整合性である。カメラ映像は端末内で解析し、外部送信しない。保存データは平文である。

機器の実際の振動・音圧・Wake Lock維持・光学読取精度・外部モニター出力は端末依存である。自動試験のモックと実機確認は分けて記録する。
