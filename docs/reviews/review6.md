# モバイルUIテストレビュー

対象は`test/ui/mobile-layout.test.js`、`test/helpers/layout.js`およびbrowser補助のmobile/touch・向き変更・実タッチ入力である。独立サブエージェント`test_review`がレビューした。

## 指摘と対応

1. 表示だけではタッチ操作不能を検出できない。実タッチでセルを開封し、スライダーで1球抽選して保存・表示まで確認する試験を追加した。
2. FREEのみ・0手では状態リセットを検出できない。開封済み0,0と実抽選1手を用い、向き変更後の保存値、カード数字、開封表示、最新球、投影手番を照合した。
3. 結果や順位の一部が隠れていても合格する。カメラ領域、照合メッセージ、25マス、順位3件へ実touchスクロールで到達するassertを追加した。
4. 投影開閉の資源解放が不足している。3回開閉し、監視数、旧Canvas、RAFを検証する試験を追加した。

修正後の独立再レビュー結果は`PASS`である。viewportとすべてのクリップ祖先、hit-test、数字の横幅収容、樽の最小寸法、右上の操作位置を検証する。scrollIntoViewやscrollTop代入は到達操作として使用しない。

7サイズの3シナリオと連続向き変更の計22ケースを追加した。既存4層テストに加えて実行する。カメラ権限失敗は試験用であり、光学性能は対象外である。実OSキーボードや端末固有のブラウザバー・ノッチ形状はエミュレーションだけで確認済みとはしない。
