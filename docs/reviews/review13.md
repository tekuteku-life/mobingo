## 実更新試験の観測

- HTTP fixtureでsw.jsと版定数を実行版から試験用9.0.0へ切替える。9.0.0は本番配信版を意味しない。
- 実waiting、取消後の同document token、controller切替後の再読込、子/親/役割の保存文字列一致を比較する。旧版Cache消去・他アプリCache保持も観測する。
- HTTP503のSW要求をサーバーでカウントし、通信失敗を最新扱いしないことを検証する。CSS503で新precacheを失敗させ、旧版継続と再試行を検証する。
- 旧版UIからabout:blankへ離脱してアプリclientを終了し、CDPの対象versionIdがactivatedになった通知後に再訪する。固定待ち時間を有効化の証拠にしない。
- 同じbrowser context内の別タブは更新後もtokenを保持し、手動確認・適用後にだけ再読込する。
- 320×568、568×320、640×280、820×1180で、版と新版文・両ボタン・取消/適用/復元/閉じるへ実touchで到達する。
- 適用中の版返信を保留して画面を閉じ、実マウスの抽選操作を開始する。返信再開後も画面/0手を保持し、抽選完了後の再適用で1手を保持する。
