# モバイルUI是正後の最終受入記録

## 対象と変更

確認日は2026年10月31日である。基準は`6d5f0b3`、製品修正は`d3e608d`、製品バージョンは1.0.2である。設計・テスト・製品修正・検証記録を工程別コミットとした。保存形式と決定論的v1生成は維持した。

- 横向きの開始・参加者セットアップを紹介と操作の2列へ、開催者セットアップを選択肢と開始操作へ分離した。
- 受付・照合カメラ・手入力・長いモーダルの幅と高さを制限し、指で内部スクロールできるようにした。
- 樽の短辺をスマートフォン縦200px以上、横160px以上に拡大した。
- 投影を15数字×5行へ整理し、縦向きの樽/最新球領域を表示高45%以内へ抑えた。
- 外部投影と操作に戻るを右上へ集約し、高さ44px、位置差20px以内を確認した。
- スライダー本体とつまみ上の縦panを許可し、横dragだけを抽選処理へ渡した。
- manifest.orientationをanyとし、PWAの縦固定を解除した。SWキャッシュ名とpackageのバージョンを1.0.2へ同期した。
