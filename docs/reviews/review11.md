# アプリ文体・更新機能の独立設計レビュー

工程はPhase 2、基準はmainの`ae2de3c`である。対象はR-20/R-21、E-17/E-18、I-17、U-10とプロセス定義である。

独立design_reviewから、既存I-13の自動skipWaiting・更新機構なしとの矛盾、版定数の同期対象漏れ、全client終了後の自然activateと旧版移行の説明不足を指摘された。既存章と同期対象を是正し、確認を必要とする起動中の強制切替と、通常ライフサイクルでの自然移行を区別した。再レビュー結果は`PASS`である。

情報モーダルへ版と確認/適用を追加し、アプリ文章を丁寧体へ統一する。更新時は実Workerの準備・版・controller切替を確認し、抽選/受付を中断せず、保存済み両ゲームと役割を保持する。製品やテストの合格を表す記録ではない。

版番号は各要素0〜999999、最大6桁、0以外の先頭0・接尾辞拒否と明記した。テスト期待値の根拠を明確にする追記であり、追加の独立設計レビューは`PASS`である。
