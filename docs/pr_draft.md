# プルリクエスト草案

## タイトル

アプリ文言の丁寧体統一とバージョン確認・更新機能の追加

## 背景

当選順の説明と空状態に文書用の「である」調が混入していた。また、実行中の版や更新の準備状況を確認して適用する操作がなかった。

## 変更内容

- アプリの説明・確認・エラーを「ですます」調へ統一し、当選順、モード説明、参加者の操作案内、アプリ情報と配信メタ情報を点検・修正する。文書本文は「である」調を維持する。
- 共通の情報画面に現在版・更新状態・確認/適用ボタンを追加する。非対応・失敗時にも現在版と商標情報を表示する。
- 新Workerのインストールと版を確認し、利用者の同意後に強制切替する。対象controllerの版を確認して1回だけ再読込する。
- 受付中・抽選の回転/球表示中を開始時・切替前・再読込前に確認し、操作中は更新済み資産を保持して再試行可能とする。
- 版ごとのCacheを検索し、新資産のprecacheはブラウザのHTTPキャッシュを使わず取得し直す。保存ゲーム・役割・他アプリのキャッシュは消去しない。
- 実行版・package/lockルート・SWキャッシュを1.2.0へ揃え、同期検査をlintに追加する。

## 確認内容

実HTTP fixtureで2版の資産を配信し、実Service Workerによる同版確認・新版待機・確認取消・適用・保存復元・オフライン再訪・取得失敗と再試行を確認する。旧版client離脱後の自然有効化、別タブ非再読込、MessagePort/タイマー/リスナー解放、閉じた旧DOMの不変、適用待ち中に始まった抽選の保護を検証する。スマホ縦横・iPad相当4サイズは新版表示・両ボタン・取消/適用/復元まで実touchで操作する。

## テスト結果

`npm run lint`はエラー0件、`npm run test:coverage`は終了コード0である。単体62・結合23・システム8・UI103、計196/196合格である。自作22ファイルすべてでLine/Branch各97%以上、最小Line98.14%・Branch97.56%である。ファイル別実測と失敗履歴は[review13](reviews/review13.md)を参照する。

## レビュー結果

設計・テスト・コードを独立サブエージェントでレビューする。更新の自然有効化と旧版移行、通信失敗の観測、Worker通知待ち、適用待ち競合の指摘を上流工程へ戻して是正した。最終の設計・テスト・コードレビューはいずれも`PASS`、未解決指摘0件である。review13に記録した。

初回取得・更新確認には通信が必要である。更新UIがない旧版は全タブ/PWA画面を閉じて再訪する。実機の本番HTTPS、配信キャッシュ、OSのPWA更新・キーボード・ブラウザUIはローカル試験の範囲外である。受付途中・入力途中の状態の新規永続化は行わない。

このファイルはローカル草案である。push・PR公開・mainへの統合は実施していない。
