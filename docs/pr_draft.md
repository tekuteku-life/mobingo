# プルリクエスト草案

## タイトル

4層テストと品質ゲートの導入、および入力・非同期処理の不具合修正

## 背景

Mobingoにはテストスイートがなく、既存の役割復元、抽選、pointerキャンセル、保存・QR入力、画面破棄の挙動を継続的に検証できない状態であった。mainに先行整備した要求・外部・内部・UI設計の契約を、4層テストと独立レビューで検証可能にする変更である。

## 変更内容

- 単体・結合・システム・Chromium UIの4層、静的検査、全自作ファイルの97%カバレッジゲートを追加する。
- Node標準暗号実装、基準v1ベクトル、独立ライン計算で生成・照合の期待値を検証する。
- host復元、抽選の未定義関数、キャンセル操作、保存スキーマとQR完全形式検査を是正する。
- 画面・カード・モーダルの生存期間を定義し、遅延処理、カメラ、RAF、監視、紙吹雪を解放する。
- 受付確定中の一覧を固定し、カード導出完了後に保存する。同じカードの再描画ではQR予約を保持する。
- 短い横画面のセットアップ・モーダル操作を修正し、モードAの成立者IDを表示する。
- 生成v1と保存キーを維持し、製品バージョンとSWキャッシュを1.0.1へ同期する。

## 確認内容・テスト結果

実測結果とファイル別カバレッジは[最終受入記録](reviews/review4.md)および[設計テスト監査](design_test_audit.md)を参照する。`npm run lint`と`npm run test:coverage`を受入コマンドとする。raw V8範囲を合算後に各ファイルを1回だけ変換し、未ロードも0%として判定する。

## レビュー結果

設計、テスト、最終コードをそれぞれ独立サブエージェントでレビューし、指摘ごとに設計・失敗試験へ戻って是正する。[レビュー記録](reviews/)に指摘と再レビュー結果を保存する。

実機カメラ、実際の音声・振動・スリープ防止、外部モニター、本番HTTPS、旧PWAからの更新はローカル自動試験の確認範囲外である。受付途中の保存復元と完全なキーボード操作は今回の受入範囲外である。

このファイルはローカル草案であり、外部へのpush・PR公開・mainへのコード統合は行っていない。
